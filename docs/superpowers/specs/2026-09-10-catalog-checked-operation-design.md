# 数据库与本地数据勾选批量操作设计

## 目标

为数据目录中的数据库数据和本地数据增加可见、可交互的复选框。复选框只用于组成右键操作的数据集合，不控制地图图层显隐，也不触发地图加载。

## 已确认的交互规则

- 数据库中的空间表、栅格表以及本地可加载图层可勾选。
- 数据库、模式、文件夹等组织节点不参与数据勾选。
- 数据库树和本地树分别维护勾选集合；批量操作解析时以当前模型节点的实际 `Qt::CheckStateRole`/`QStandardItem::checkState()` 为准，辅助集合只用于状态保存和显示。
- 右击已勾选的数据时，批量类操作使用当前树中全部已勾选数据。
- 右击未勾选的数据时，操作只针对当前右击项，已有勾选状态不被清除。
- “添加到地图”“刷新”“批量导出数据”支持勾选集合。
- “基本信息”“重命名”“数据裁剪”“导出数据”保持单对象语义，仅作用于当前右击项。

## 实现方案

采用现有模型扩展方案，避免替换 QGIS 浏览目录和已有上下文菜单逻辑。

### 数据库树

数据库树继续使用 `QStandardItemModel`。空间数据项设置 `Qt::ItemIsUserCheckable`，勾选状态通过 `Qt::CheckStateRole` 渲染。使用数据库、模式、表名、图层类型和几何列构成稳定标识，在刷新数据库目录后恢复仍存在数据项的勾选状态。

### 本地树

本地树继续使用 QGIS `QgsBrowserProxyModel`。增加一个轻量代理扩展，为可加载图层提供 `Qt::ItemIsUserCheckable`、`Qt::CheckStateRole` 和 `setData()` 支持。勾选集合按 `QgsDataItem::path()` 保存，从而不依赖刷新后失效的行号或临时模型索引。

### 右键目标解析

右键菜单打开时，先判断当前项是否已勾选：

1. 当前项已勾选：直接遍历同一数据源树当前模型/代理树中的勾选项，生成批量目标集合。
2. 当前项未勾选：只生成当前项目标。

批量目标只传递给批量安全的操作。添加到地图时对 URI 去重；数据库刷新合并为一次目录刷新；批量导出时统一收集 URI 并只选择一次输出目录。

## 视觉样式

五个主题的 `QTreeView` 均增加复选框指示器规则，复用对应主题中图层管理使用的高对比边框、未选中背景和选中颜色。现有树分支箭头样式保持不变。

## 异常与兼容性

- 刷新或断开本地目录后，只从当前代理树中收集仍存在且实际勾选的节点，不依赖对懒加载路径的反查；失效节点不影响剩余勾选项。
- 不支持矢量或栅格加载的数据库表不显示数据勾选框。
- 没有有效批量目标时，批量菜单项保持禁用。
- 保留现有单项双击加载、目录刷新、导入、重命名和地图加载回调行为。

## 验证范围

- 静态检查数据库树和本地树都提供可勾选模型能力。
- 静态检查右键已勾选项和未勾选项分别走批量/单项目标解析。
- 静态检查五个主题都包含 `QTreeView::indicator` 样式。
- 编译 Release x64，确认无新增编译错误。
- 运行现有相关验证脚本，并增加针对目录勾选和批量右键目标的验证脚本。
