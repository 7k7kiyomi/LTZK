# QGIS 风格工具栏与图层操作设计

## 目标

将地图画布工具入口调整为用户可显示、隐藏、移动和浮动的工具栏；补充按图层类型区分的右键菜单；扩展图层管理顶部的可见性、图例过滤和地图主题操作。三个入口复用一致的图层树、地图画布和 QGIS 工程动作。

## 首期范围

### 地图工具栏

- 在地图画布面板内使用嵌入式 Qt 主窗口承载原生工具栏，默认停靠在画布上方，支持拖动、浮动、横竖方向切换和重新打开。
- 在地图面板上方提供固定的“工具栏”管理按钮，并保留工具栏右键菜单；从固定菜单逐条切换显隐，支持恢复默认布局。
- 只有登录且当前显示地图工作区时才显示这些工具栏；进入登录、模块首页或权限管理页时，停靠栏与浮动栏都收起。
- 分别保存地图工具栏的位置布局和用户显隐偏好；页面切换造成的临时隐藏不覆盖用户选择。
- 提供工程/数据导入、地图导航、查询测量和要素选择工具栏。复用现有打开/保存工程、添加矢量/栅格、缩放、平移、初始视图等动作。
- 添加当前图层/选中要素定位、上一视图/下一视图、识别要素、测距/测面和图层样式面板入口；图标有提示和活动状态，依赖图层的动作按条件禁用。
- 旧画布角落的单按钮菜单不再作为工具入口。

### 图层右键菜单

- 图层树组和图层保留已有重命名、缩放、属性表、SHP 色彩及移除功能。
- 复用 QGIS 默认图层树动作，增加缩放到选中项/组、缩放至要素选择、要素计数、概览、移动出组、移动到顶部/底部、分组和互斥组。
- 增加矢量图层复制、过滤和导出入口；栅格图层按类型显示波段拉伸、样式/属性及导出入口。未实现的专用功能不显示为可执行菜单。
- 多选时应用于选中顶层节点，避免子组及其后代重复操作。
- 将“移除选中节点”与“批量移除已勾选节点”区分，后者沿用现有整树复选批量移除行为；均仅从当前工程移除，不删除底层数据。

### 图层管理顶部

- 保留新建组、展开、折叠、移除。
- 增加图层样式面板切换、图层树名称搜索、图例按地图范围过滤、图例表达式过滤入口。
- 增加地图主题菜单：显示/隐藏全部或选中项、独立反转、隐藏未选中项、新建/应用/更新/重命名/删除主题。
- 搜索只影响树中可见节点，不更改图层数据过滤；地图范围图例过滤不改变要素数据。
- 移除、可见性、过滤、主题动作使用图层管理自身的 QGIS 模型，并同步刷新地图画布。

## 实现与兼容

- 目标版本为 Qt 5 与 QGIS 3.28.15。
- 在现有 `LTZK` 窗口、`QgsLayerTreeView`、`QgsLayerTreeModel` 和工程动作上实现，优先调用 QGIS 3.28 自带的图层树默认动作、地图主题集合和图例过滤 API。
- 栅格 100% 原始分辨率、分类图例样式编辑、完整几何编辑工具和复杂数据修复保留为后续范围，避免菜单暴露空功能。

## 验收

- 四类工具栏只出现在已登录的地图工作区，默认停靠在地图画布上方；可以独立显隐、拖动或浮动。
- 从地图工作区离开后，所有浮动工具栏均隐藏；再次进入时恢复用户的显隐偏好和上次布局。
- 即使用户隐藏全部工具栏，地图面板上的固定管理按钮仍可重新打开工具栏或恢复默认布局。
- 当前画布工具和选中图层改变时，工具按钮状态及可用性同步更新。
- 右键菜单按组、矢量、栅格和多选上下文变化；所有移除入口遵守各自明示的节点范围。
- 顶部名称搜索可清空；图例地图过滤可关闭；地图主题可保存、再次应用、更新、改名和删除。
- 不支持的类型操作置灰或隐藏，任何移除都不会调用底层数据删除操作。
