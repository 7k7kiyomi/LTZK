# 右键菜单“按制图导出”显示名称设计

## 目标

将成果目录相关右键菜单中显示的“按主区裁切导出”改为“按制图导出”，仅调整用户可见的菜单名称，不改变现有按主区裁切导出的业务行为。

## 范围与约束

- 成果目录节点和成果产品节点的右键菜单都显示“按制图导出”。
- 保留现有 `mainAreaExport` / `actMainArea` 变量、`main-area` 操作标识及 `onExportByMainAreaClip()` 调用链。
- 不修改主区裁切导出对话框标题、校验提示、导出完成提示、注释或内部函数名称。
- 不将“按主区裁切导出”做全局替换，避免改变业务语义文本。

## 实现方案

在以下右键菜单构造位置，仅替换传给 `QMenu::addAction()` 的显示字符串：

- `DataCatalogWidget.cpp` 中目录节点菜单和产品节点菜单各一处。
- `map_product_manager_tools/ui_class/product_storage_dialog.cpp` 中目录节点菜单和产品节点菜单各一处。

菜单动作对象及其 `triggered` 信号连接保持不变，因此菜单显示名称变化不会影响已有导出流程。

## 测试与验收

- 先扩展现有 `tests/verify_data_catalog_product_tree.ps1`，要求它检查新菜单名称存在，并检查四个右键菜单定义位置不再使用旧名称。
- 运行该验证脚本，确认修改前测试因缺少新名称而失败。
- 修改四处菜单显示字符串后重新运行脚本，确认验证通过。
- 额外使用 `rg` 检查旧名称仍只存在于对话框/提示/注释等非右键菜单语境中，内部 `main-area` 标识未被改动。

## 错误处理与兼容性

本需求不改变数据导出、权限判断、回调分发或异常处理；因此不引入新的运行时错误路径，也不需要数据库或资源文件迁移。
