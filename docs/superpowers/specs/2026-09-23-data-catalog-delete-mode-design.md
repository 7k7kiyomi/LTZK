# 数据目录“删除数据”双模式设计

**日期：** 2026-09-23  
**范围：** `DataCatalogWidget` 的数据库列表、本地列表及成果目录访问层

## 1. 目标

数据库列表和本地列表的数据节点右键菜单都提供：

- `重命名`
- `删除数据`

右键菜单不增加独立的 `隐藏` 项。用户点击 `删除数据` 后，在确认弹窗中明确选择以下两种模式之一：

1. **仅从平台列表移除（保留源数据）**：只写入平台侧持久化移除记录，数据源本身不变；刷新平台或重新启动后仍不显示。
2. **永久删除源数据**：根据节点来源删除数据库成果/数据库图层或本地数据文件，操作前显示不可恢复警告并要求确认。

默认选中第一种模式，避免用户误删源数据。

## 2. 右键菜单范围

### 2.1 数据库列表

- 成果目录中的成果节点、代表单个或一组成果的图层目录节点：显示 `重命名` 和 `删除数据`。
- 无成果数据的普通目录、数据库根节点和结构目录：保留现有目录操作，不显示 `删除数据`。
- 无成果目录结构的旧式数据库视图中，矢量/栅格图层节点显示 `重命名` 和 `删除数据`。
- 普通数据库表、Schema、提示行和数据库根节点不执行数据删除。

### 2.2 本地列表

- 具有可加载本地 URI 的矢量/栅格数据节点显示 `重命名` 和 `删除数据`。
- 本地文件夹、Favorites 根节点和连接入口不显示 `删除数据`，现有连接/刷新/目录操作保持不变。
- 删除本地数据时识别已有的伴随文件规则；例如 Shapefile 的 `.dbf`、`.shx`、`.prj`、`.cpg` 等与主文件作为同一数据集处理。

## 3. 删除弹窗与分流

`删除数据` 统一进入一个自定义确认对话框，而不是用含糊的单一“是/否”消息框。对话框包含：

- 当前显示名称和来源（数据库/本地）；
- 两个互斥单选项：
  - `仅从平台列表移除（保留源数据）`；
  - `永久删除源数据`；
- 永久删除模式下显示数据库对象、文件路径和伴随文件清单；
- 永久删除模式下显示“此操作不可恢复”的警告；
- `确认` 和 `取消` 按钮。

用户取消或关闭对话框时不改变任何平台状态和源数据。确认后按 `CatalogSource` 分流：

```text
数据库节点 -> 数据库平台移除记录，或数据库真实删除
本地节点   -> 本地平台移除记录，或本地文件真实删除
```

### 3.1 仅平台侧移除

平台移除记录使用稳定来源键保存到平台侧设置，不改数据库和文件系统：

- 数据库成果使用数据库连接身份加 `productId`；旧式数据库图层使用连接身份、Schema、表名、图层类型和几何列。
- 本地数据使用规范化/规范路径；无法取得文件路径时使用 QGIS 数据项路径作为后备键。

数据库目录重建时跳过已移除的成果/图层；本地自定义浏览代理模型在 `filterAcceptsRow()` 中过滤已移除的本地数据。移除集合在构造、刷新和配置切换时重新读取，保证重启后仍生效。

### 3.2 永久删除数据库数据

- 成果目录成果节点调用 `DataCatalogProductCatalog` 的事务接口。
- 事务内删除成果关联的版本 Large Object、关联图层注册信息、成果图层表和 `product_metadata` 记录；任一步失败则回滚。
- 图层目录节点删除其代表的成果记录，不把普通目录删除误当成数据删除。
- 旧式数据库视图只允许对已识别的矢量/栅格图层执行带引号的 `DROP TABLE ... CASCADE`；普通表不显示该操作。
- 成功后刷新数据库列表，并清理已删除节点对应的勾选缓存、显示别名和平台移除记录。

### 3.3 永久删除本地数据

- 从当前数据项 URI 取得本地绝对路径，去重后生成待删除数据集清单。
- 普通文件使用现有伴随文件识别逻辑，将主文件和伴随文件一起删除。
- 文件地理数据库等目录型数据集使用目录递归删除，但禁止删除 Favorites 根目录或连接文件夹根目录。
- 删除前在弹窗中展示最终路径；删除失败时保留失败项并报告原因，成功项仍从平台列表刷新移除。
- 删除完成后刷新对应 QGIS Browser 节点和 Favorites 视图；如果数据正在被其他程序占用，提示用户关闭占用后重试。

## 4. 重命名

重命名沿用现有安全语义：只修改平台显示名称，不修改数据库表名、数据库 Schema、本地物理文件名或文件夹名。

- 数据库成果/图层使用稳定键保存显示别名，数据库加载时重新应用。
- 本地数据由 `CatalogBrowserProxyModel` 对显示角色应用路径别名，刷新后保持本次平台会话内的显示名称。
- 已有数据库目录重命名和 Favorites 文件夹显示别名行为保持不变。
- 空名称、换行和取消输入不产生变化。

## 5. 实现边界

### `DataCatalogWidget.h/.cpp`

- 增加删除模式、确认对话框、平台移除键读写和数据库/本地删除处理器。
- 在成果节点菜单和旧式图层菜单中加入 `删除数据`，移除任何独立 `隐藏` 菜单文案。
- 扩展本地浏览代理模型以过滤持久化的平台移除路径，并为本地数据显示别名。
- 数据库树重建、本地 Browser 刷新和数据库连接切换时应用平台移除记录。
- 保留已有导出、导入、地图加载、目录删除和连接逻辑。

### `DataCatalogProductCatalog.h/.cpp`

- 将现有事务删除逻辑提炼为公开的单成果/多成果删除接口。
- 保持 Large Object、版本记录、图层注册表、图层表和成果元数据的一致性。
- 删除接口不负责平台侧移除状态；平台移除状态只由宿主维护。

### 测试

新增静态回归检查，至少验证：

- 两棵列表的数据右键菜单均包含 `重命名`、`删除数据`；
- 源码中没有新增独立的 `隐藏` 菜单动作；
- 删除弹窗存在两种模式且默认是平台侧移除；
- 平台移除键使用 `QSettings` 并在数据库/本地加载和代理过滤路径中生效；
- 数据库永久删除经过事务接口，本地永久删除包含伴随文件处理和刷新；
- 普通目录、数据库根节点和本地连接根节点不会误启用永久删除；
- Release x64 构建通过，已有数据目录、导入、导出和地图加载回归检查不受影响。

## 6. 验收标准

1. 数据库成果节点和本地数据节点右键均能看到 `重命名`、`删除数据`，看不到 `隐藏`。
2. 点击 `删除数据` 后，用户能清楚选择“仅从平台列表移除”或“永久删除源数据”。
3. 平台侧移除不会改变数据库记录或本地文件，刷新和重启后仍不显示。
4. 数据库永久删除事务失败会回滚；本地永久删除失败会报告失败路径，不静默丢失结果。
5. 取消确认不会改变任何数据；永久删除前始终显示明确的不可恢复警告。
