# 地图智能综合结果面板接入设计

## 目标

让 `plugin_map_generalization.dll` 产生的检查/错误结果 `.shp`，按照地图成果质检子平台现有规则，从用户选择的结果输出路径中扫描并加载到结果面板，同时避免两个业务模块的结果互相串台。

## 现状

- `LTZK::refreshQualityResultOutputDirectories()` 会从可见插件窗口中读取语义为结果输出路径的目录。
- `LTZK::syncQualityResultShpLayers()` 递归扫描这些目录下的新 `.shp`，加载为仅注册到 QGIS 工程的结果图层。
- `LTZK::refreshQualityResultPanel()` 展示结果图层和错误字段，并支持显隐与定位。
- 结果扫描触发条件目前是插件 ID 包含 `quality`。
- 结果面板与结果图层仅在“地图成果质检”模块中刷新/加入地图画布；智能综合插件绑定在“智能综合”菜单下，但没有结果扫描标记。

## 设计

### 1. 配置驱动的扫描触发

扩展 `PluginDefinition`，增加 `watchResultOutputs` 布尔字段，默认值为 `false`。在主配置中将地图成果质检插件和地图智能综合插件都设置为 `true`。执行配置中声明需要监控结果输出的插件动作时，统一执行：

1. 动作前记录扫描起始时间并读取当前可见插件窗口中的结果输出目录；
2. 触发插件动作；
3. 动作后重新读取输出目录、扫描新 `.shp` 并刷新结果面板；
4. 继续通过定时器监控动作完成后延迟生成的 `.shp`。

### 2. 两个平台复用同一结果管线

保留既有输出目录识别、递归 `.shp` 扫描、字段回退、数量上限、显隐和定位逻辑。只将结果管线从“质检专属触发”扩展为“配置声明触发”，不扫描未被插件选择的普通成果目录。

### 3. 按业务模块隔离结果

结果图层加载时记录当前业务模块标题。结果面板只展示当前模块所属的结果图层；地图画布也只加入当前模块勾选可见的结果图层。两个结果模块都保留结果面板，其他模块切换时清空面板显示并隐藏结果图层，但不删除已加载数据。

### 4. 通用界面文案

将仅适用于质检平台的“质检图层 shp”汇总/列标题改为“检查结果 shp”，以同时覆盖质检和智能综合产生的错误结果。

## 涉及文件

- `PluginBindingConfig.h/.cpp`：增加并解析 `watchResultOutputs`。
- `config/plugin_bindings.json`：声明两个结果插件的监控开关。
- `LTZK.h`：增加结果图层所属模块的状态和必要的通用判断接口。
- `LTZK.cpp`：扩展模块切换、动作触发、结果面板刷新和地图画布图层过滤。
- `tests/verify_generalization_result_panel_binding.ps1`：新增静态回归校验。
- 运行时/发布配置副本：同步配置字段，避免发布包丢失该能力。

## 验收标准

1. 在地图智能综合插件中选择结果输出路径并执行动作后，新生成的错误 `.shp` 自动出现在结果面板。
2. 结果面板使用与地图成果质检相同的路径扫描和字段解析规则。
3. 智能综合结果不会显示在地图成果质检模块，质检结果不会显示在智能综合模块。
4. 切换到其他模块时，结果图层不出现在地图画布中。
5. 现有地图成果质检相关校验全部继续通过。
