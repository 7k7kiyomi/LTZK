# 图层管理组右键操作设计

## 目标

为“图层管理”中的组节点增加右键“重命名”和“删除”能力，并让多个组可以通过一次右键操作移除。该删除只操作当前 QGIS 工程的图层树，不删除本地源文件、数据库表或数据库成果数据。

## 交互范围

- 图层树启用扩展多选。
- 右键已选中的节点时保留已有多选；右键未选中的节点时只选中该节点。
- 组节点右键显示“重命名”和“删除组”。
- 单个图层继续使用现有图层菜单和“移除图层/组”入口。
- 选中多个顶层组后，在任一选中组上右键并点击“删除组”，一次移除全部选中组。
- 组和图层混合多选时，移除操作处理全部选中的顶层节点；选中组的子节点不重复处理。

## 行为

### 重命名

- 仅允许单个组执行重命名。
- 使用输入框取得非空名称，拒绝换行文本。
- 调用 `QgsLayerTreeGroup::setName()`，保留 QGIS 工程现有的树模型和工程脏状态机制。

### 删除/移除

- 组节点通过其父节点的 `removeChildNode()` 从图层树移除，组内子图层随组节点离开图层管理。
- 单独选中的图层仍通过现有 `QgsProject::removeMapLayer()` 移除。
- 不调用任何本地文件删除、数据库 DROP 或成果目录删除 API。
- 移除后刷新当前图层、地图画布和图层树状态；已选节点包含祖先组时，只处理祖先组，避免悬空指针和重复移除。
- 对自动生成的质检成果组记录被移除的目录路径，后台成果同步在当前监控会话中不重新创建这些组；开始新的成果监控时清除该会话状态。

## 实现边界

- 修改 `LTZK::initLayerTreeView()` 的上下文菜单和选择行为。
- 扩展 `LTZK::removeLayer()` 读取 `QgsLayerTreeView::selectedNodes(true)`。
- 新增组重命名 helper，菜单只捕获有效组节点。
- 保留现有工具栏“移除图层/组”入口，并让它复用多选移除逻辑。

## 验证

- 静态契约测试检查扩展多选、组菜单、组重命名、顶层节点多选移除和不触碰源数据删除 API。
- 运行既有图层树/工程相关回归检查。
- 使用 Visual Studio Release 配置构建 `LTZK.vcxproj`。
