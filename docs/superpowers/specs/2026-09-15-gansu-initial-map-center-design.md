# 默认甘肃地图初始居中设计

## 目标

进入业务页面后，默认加载的甘肃省地图应以实际显示的甘肃底图范围为中心；保持现有地图缩放级别、图层样式、拖拽和平移行为不变。

## 原因与范围

`LTZK::setGansuInitialMapView()` 当前先设置一个固定初始范围，又用固定坐标 `103.8263, 36.0594` 覆盖视图中心。该坐标与经过“省级=甘肃省”筛选后实际显示的底图范围中心不一致，导致地图视觉上偏向左上。本次只调整初始中心计算，不修改默认范围、底图筛选、样式或交互。

## 方案

设置初始范围后，遍历项目中的系统底图图层，将其图层范围转换到地图画布的输出坐标系，并以该范围的中心作为 `QgsMapCanvas` 中心。若底图尚未加载、无效或范围为空，则回退到现有固定中心，保证异常情况下仍有稳定的默认视图。

调用顺序保持为“设置 EPSG:3857 → 设置现有初始范围 → 设置实际底图中心 → 刷新 → 保存初始视图”，因此缩放和后续“恢复初始视图”逻辑不变。

## 测试与验收

- 新增静态回归脚本，检查系统底图范围被转换到输出坐标系、中心取自该范围，并且中心设置发生在初始范围设置之后。
- 检查固定中心仍作为回退值保留。
- 运行既有甘肃底图、主题工作区和渲染稳定性验证脚本。
- 完整编译若环境提供 `msbuild`，否则明确记录构建工具不可用。
