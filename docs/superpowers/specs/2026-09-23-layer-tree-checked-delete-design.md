# 图层树复选框批量删除设计

## 目标

右键删除图层管理节点时，将整棵图层树中已经勾选的组和图层作为删除目标，即使用户没有使用 Ctrl/Shift 进行节点多选，也能一次删除所有勾选项。同时保留现有的鼠标选择删除行为。

## 根因

当前 `LTZK::removeLayer()` 只读取 `QgsLayerTreeView::selectedNodes(true)`，而图层树的可见性复选框状态保存在 `QgsLayerTreeNode` 的可见性状态中，两者不是同一套选择状态。因此仅勾选节点但没有选中节点时，删除入口无法发现这些目标。

## 行为规则

1. 删除目标由三部分合并：
   - 整棵图层树中通过可见性复选框选中的节点；
   - 当前 Ctrl/Shift 选中的顶层节点；
   - 右键点击的上下文节点。
2. 组的复选框显示三态：
   - 组及全部后代均勾选：组为 `Checked`，删除组本身及其整棵子树；
   - 组及后代只有部分勾选：组为 `PartiallyChecked`，保留组，只递归删除勾选的子组和图层；
   - 组及全部后代均未勾选：组为 `Unchecked`，不删除组，但继续检查后代，以兼容组状态和子节点状态暂时不一致的情况。
3. 删除集合自动去重。已进入集合的父组覆盖其所有后代，后代不再单独处理；根节点永远不能成为删除目标。
4. 删除前显示确认框，明确数量和范围是“整棵图层树中的已勾选/选中项”。操作只从当前 QGIS 工程图层树移除组或图层，不删除本地文件、不删除数据库表或数据库成果。
5. 取消确认时不改变树、工程和复选框状态。

## 实现边界

- 在 `LTZKLayerTreeModel::data()` 中为组计算三态复选框状态；现有 `setData()` 的递归可见性逻辑保持不变。
- 在 `LTZK.cpp` 匿名命名空间中增加目标收集、父子去重和删除摘要 helper，避免将临时删除中的节点指针暴露给异步回调。
- `removeLayer()` 继续作为工具栏入口；右键菜单在构建时快照删除目标，并通过 lambda 调用统一删除执行 helper，避免菜单弹出期间重新读取已变化的选择状态。
- 删除阶段先快照目标信息和质检结果组路径，再删除顶层组、批量移除有有效图层 ID 的图层，最后清理没有关联 `QgsMapLayer` 的树节点。

## 验证

- PowerShell 静态回归检查必须确认三态组状态、整树递归、复选框目标与显式选择合并、父子去重、确认提示和不删除源数据。
- 运行既有图层树可见性、组右键菜单、节点转换保护检查。
- 使用 Visual Studio Release x64 构建 `LTZK.vcxproj`。
