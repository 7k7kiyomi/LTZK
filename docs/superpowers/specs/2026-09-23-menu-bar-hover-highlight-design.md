# 顶部功能按钮悬停浮起设计说明

**状态：** 已获用户确认，采用方案 B；已修正到可见顶部功能按钮并通过 Release x64 构建，待实际界面确认悬停观感

**日期：** 2026-09-23

## 目标

增强工作区顶部功能按钮的鼠标悬停反馈，让用户移动鼠标到插件功能、返回首页或退出账号按钮时，能看到按钮明显浮起。

## 已确认的视觉方向

采用方案 B：主题强调色描边 + 明亮顶部边缘 + 底部支撑线 + 动态投影。

- 样式作用于实际显示的 `QToolButton[topBarTool="true"]`，包含动态插件按钮、返回首页和退出账号。
- 悬停时边框、顶部亮边和底部支撑线同时强化，主题颜色与当前平台风格一致。
- `QGraphicsDropShadowEffect` 在鼠标进入/离开时平滑调整模糊半径和阴影偏移，形成浮起层次。
- 按钮所在滚动内容上下预留空间，避免滚动视口裁掉阴影。

## 范围

主要交互目标是顶部工作区按钮：

- `QToolButton[topBarTool="true"]:hover`
- `QToolButton[topBarTool="true"][topBarRaised="true"]`

保留的主菜单栏 QSS 规则不再承担此功能，因为初始化时主 `QMenuBar` 会被隐藏。

## 实现边界

- 修改五套现有 QSS 文件，并在 `LTZK.cpp` 中为可见顶部按钮安装轻量悬停控制器。
- 保持菜单动作绑定、插件菜单层级和业务逻辑不变。
- 复用现有主题切换逻辑，并同步刷新悬停投影颜色。
- 静态验证脚本检查五套主题的可见按钮样式、悬停控制器、主题刷新和阴影留白。

## 验收标准

1. 五套主题的可见顶部功能按钮悬停时都有明亮描边、顶部亮边和底部支撑线。
2. 鼠标进入/离开时阴影平滑变化，按钮文字仍可读。
3. 动态插件按钮、返回首页和退出账号均启用相同交互。
4. 滚动视口为阴影保留空间，按钮未悬停时布局不发生跳动。
5. 静态验证脚本通过，Release 配置能够重新编译并成功构建。
