# 子平台标题背景透明化设计

## 目标

让四个业务模块和“权限管理”进入子平台后显示的标题，其标题区域背景与所属顶部栏保持透明融合，消除标题周围继承主题色形成的矩形色块。

## 范围与边界

- 覆盖工作区页面的 `m_activeModuleTitle`，包括四个业务模块切换后的子平台标题。
- 覆盖权限管理页面的 `titleLabel`，即“权限管理子平台”标题。
- 仅处理标题标签及其承载容器的背景绘制。
- 保留现有标题文字、字号、字重、颜色、阴影、左侧蓝色/橙色强调线、顶部栏背景和底部边线。
- 不改变模块切换、返回首页、退出账号、顶部按钮、插件内容区及业务功能。
- 三套平台主题（科幻、黑色、白色）保持一致的透明语义，并分别保留原有主题颜色。

## 现状与原因

工作区标题位于 `titleContainer` 中。虽然 `QLabel` 的通用规则已设置透明背景，但承载标题的普通 `QWidget` 会继承主题中的全局 `QWidget` 背景，因此在标题周围形成与顶部栏不同的矩形色块。权限管理标题直接使用 `QLabel`，也需要通过对象级标题规则显式声明透明背景，避免全局样式变化时回退为不透明绘制。

## 方案

采用对象级 QSS 透明覆盖，并为工作区标题容器补充明确的对象名：

1. 在工作区标题容器上设置 `workspaceTitleContainer` 对象名。
2. 在三套主题 QSS 中增加 `#workspaceTitleContainer { background: transparent; border: 0; }`。
3. 在三套主题的 `#dashboardTitle` 规则中增加 `background: transparent;`，同时保留现有左侧强调线和内边距。
4. 权限管理标题继续复用 `dashboardTitle` 规则，不新增页面专属标题样式。

这样工作区和权限管理共享同一标题样式契约：标签本身透明，工作区额外的承载容器也透明；顶部栏仍负责绘制整体主题背景。

## 视觉验收标准

- 在科幻、黑色、白色主题下，标题文字周围不再出现独立矩形色块。
- 标题左侧强调线仍可见，颜色分别保持青蓝、橙色、蓝色。
- 标题顶部栏的整体背景和底部边线不被清除。
- 四个业务模块与权限管理的标题表现一致，不因进入路径不同而出现背景差异。
- 标题文字的可读性、对齐位置和现有阴影效果不变。

## 验证

- 增加静态回归检查，确认三套 QSS 均为 `#dashboardTitle` 和 `#workspaceTitleContainer` 声明透明背景。
- 检查源码确认工作区标题容器设置了 `workspaceTitleContainer` 对象名，权限管理标题仍使用 `dashboardTitle`。
- 运行聚焦验证脚本，并执行 `git diff --check`（若工作区提供 Git 元数据）。
- 使用现有 Visual Studio 工程执行 Release 编译；若构建环境不可用，记录实际阻塞原因。

## 非目标

- 不删除顶部栏背景，不把整个子平台页面设为透明。
- 不移除标题的颜色、字体或强调线。
- 不修改插件分组框标题、表格标题或首页主标题的背景样式。
