# 权限管理子平台标题样式统一设计

**状态：** 已获用户确认，待实施

**日期：** 2026-09-01

## 目标

使“权限管理子平台”的标题在科幻系、黑色系、白色系、绿色系和灰色系五种平台风格下，与四个业务子平台标题使用完全一致的标题样式和主题背景表现。

## 设计

- 权限管理标题继续使用对象名 `dashboardTitle`，复用四个业务子平台的字体、字号、字重、文字颜色、左侧强调线、透明背景和对齐方式。
- 权限管理顶部栏使用当前平台风格的顶部栏背景，不再在页面初始化时固定使用科幻系/深色背景。
- 五套 QSS 均同时为 `#dashboardTopBar` 和 `#accessControlTopBar` 提供对应主题的顶部栏规则，使两个子平台标题的可见背景一致。
- 标题阴影也跟随当前主题的业务子平台标题设置；不改变权限管理页面的返回首页、退出账号、表格和编辑区样式。

## 实现边界

需要修改：

- `LTZK.cpp`：权限管理页的样式初始化、标题阴影设置。
- `Resources/styles/ltzk_sci_fi.qss`
- `Resources/styles/ltzk_black.qss`
- `Resources/styles/ltzk_white.qss`
- `Resources/styles/ltzk_field_notes.qss`
- `Resources/styles/ltzk_steel_warm_white.qss`
- `tests/verify_access_control_title_style.ps1` 或新增专门的一致性回归检查。

不修改：

- 权限管理业务逻辑、数据库访问和权限判断。
- 四个业务子平台的布局和标题文字。
- 权限管理页面内容区控件的配色和交互行为。

## 验收标准

1. 五套主题中，`#dashboardTitle` 的标题规则同时适用于业务工作区和权限管理页。
2. 五套主题中，`#accessControlTopBar` 与 `#dashboardTopBar` 使用相同的顶部栏背景和边线颜色/渐变。
3. 权限管理页不再调用固定科幻样式作为当前主题的最终样式来源。
4. 现有标题透明化检查、权限管理标题检查和平台主题检查全部通过。
5. Release 配置能够完成编译；如当前目录没有 Git 元数据，不执行提交并如实报告。

## 验证策略

先增加一个针对“权限管理页使用当前主题样式”和“五套 QSS 顶部栏规则成对存在”的静态回归检查，确认它在现有代码上按预期失败；然后完成最小源码/QSS 修改，重新运行该检查及相关已有检查，并执行 Release 编译验证。
