# 权限管理角色下拉框首次展开修复设计

## 目标

修复权限管理页面首次打开角色下拉框时只显示一项、出现异常滚动条以及下拉箭头不可见的问题；角色列表仍由现有 `LTZKAccessControlDialog` 同步维护，不改变数据库和权限业务逻辑。

## 方案

权限管理页是预先创建、首次访问时才显示的嵌入式页面。应用级 `eventFilter` 当前会把所有非主窗口的 `QEvent::Show` 都当成插件窗口初始化，并异步重新套用平台样式。Qt 的角色下拉框弹出容器属于 `Qt::Popup`，因此首次创建时会被错误纳入这条异步路径。修复时跳过 `Qt::Popup` 和 `Qt::ToolTip` 窗口，让下拉弹出容器沿用应用级样式，避免首次展示期间发生尺寸/样式重算。

五套平台 QSS 为 `QComboBox::down-arrow` 明确指定已有的深色或浅色 SVG 资源。这样权限管理角色下拉框不再依赖平台原生箭头绘制，且不修改角色项、当前值或数据库读取流程。

## 验收标准

1. 角色下拉框仍包含“数据操作员”“数据使用者”“数据库管理员”三项。
2. `eventFilter` 不再为 Qt 弹出窗口调度插件窗口样式初始化。
3. 五套主题均有显式的 `QComboBox::down-arrow` 资源规则。
4. 现有源码回归检查和 Release x64 构建通过。
