# QGIS 原生图层添加与 GeoPDF 支持设计稿

日期：2026-10-22

状态：已按本设计实现并完成验证（2026-10-23）。

## 目标与一致性基准

将平台的图层添加流程接入当前依赖的 QGIS 3.28.15 原生数据源管理器，保持该版本的来源分类、文件/目录/数据库/网络来源选择、编码、驱动选项和子图层选择行为。通过矢量或栅格入口加载 GeoPDF，数据加入平台现有项目、图层树和地图画布。

一致性指当前版本可用的数据提供者及其添加流程；不将其他版本新增的数据提供者或 QGIS 全部编辑、分析功能计入此改动。数据库和网络来源的可用性取决于已部署驱动、服务及用户连接权限。

## 已确认的现状

- 平台为 Qt/C++，已经链接 qgis_core、qgis_gui、qgis_app 和 GDAL。
- LTZK.cpp 的 on_actionAddVectorData_triggered 与 on_actionAddRasterData_triggered 使用普通文件选择框。
- isVectorLayerFile / isRasterLayerFile 依赖固定扩展名，均未接纳 PDF；addLayerFiles 对一个文件只构造单个图层，且要求来源为本地普通文件。
- 当前 WMS/WFS/WCS 入口已经使用 QGIS 来源选择组件，但没有统一的数据源管理窗口。
- 本机 QGIS 头文件提供 QgsDataSourceManagerDialog、QgsBrowserGuiModel、QgsProviderSublayerDetails、QgsSublayersDialog。
- 实测当前 OSGeo4W 的 gdalinfo --format PDF 与 ogrinfo --formats：PDF 同时支持 Raster、Vector、Raster subdatasets、Multiple vector layers，HAVE_POPPLER=YES。
- 工作目录没有 Git 仓库，设计稿不能在此提交到 Git。

## 可选方案

1. **推荐：复用 QGIS 原生数据源管理器。** 使用真实提供者页面，平台负责处理添加信号、子图层选择和项目注册。一致性最高，也能使用现有运行库的 GeoPDF 能力。
2. 自行仿制截图界面。需要重复维护 QGIS 提供者选项与连接逻辑，界面相似无法保证数据加载行为相同，不推荐。
3. 只给现有文件框增加 PDF。范围最小，但不满足数据源管理器及多子图层选择要求，不推荐。

## 交互设计

- 增加统一“数据源管理器”入口。
- 现有“添加矢量数据”直接打开原生管理器的 ogr 页面，“添加栅格数据”打开 raster 页面。
- 复用平台已有入口位置和主题规则；保留 QGIS 原生控件、分类、选项及中文翻译。
- 浏览器、数据库、服务、网格、点云、矢量瓦片等页面按本机提供者注册情况展示。每个展示出的添加动作必须有实际处理逻辑；不能仅展示页面却丢弃添加请求。
- 保持窗口可重复打开，关闭和再次打开不得重复连接信号或访问已销毁对象。

## 组件与数据流

将来源管理和加载协调逻辑放入职责独立的实现单元，避免继续把全部逻辑堆入 LTZK.cpp。

1. 管理器使用共享 QgsBrowserGuiModel，并设置平台地图画布。
2. 接入单个/批量矢量与栅格、数据库、网格、点云、矢量瓦片、浏览器 URI、文件打开、选中矢量图层替换、状态及连接刷新信号。
3. 加载路径接收 QGIS URI、提供者键、编码和来源类型，不能用本地文件存在性检查拒绝数据库、网络或子数据集 URI。
4. 对容器来源查询真实子图层；存在多个候选时调用 QGIS 子图层选择组件。取消选择不会注册任何图层。
5. 加载有效图层后统一加入现有 QgsProject、图层树和画布，更新活动图层；用户可缩放至新图层。导入不得强制恢复甘肃默认地图视图。
6. 原文件拖放路径复用相同加载协调逻辑，PDF 同时具备矢量与栅格候选时显式选择加载类型，避免根据扩展名固定判断。

## GeoPDF 行为

- 栅格入口：由 GDAL 读取 PDF 页面及地理参考，按实际 CRS 和范围叠加；多页面/子数据集按驱动返回的候选选择。
- 矢量入口：由 OGR 查询可读取的矢量子图层，按选择加载多个图层并保留可读取的属性。
- 只有矢量图层存在时才提供矢量添加结果；不能把 PDF 页面上的所有图形都承诺为可编辑 GIS 要素。
- 没有地理参考的普通 PDF 必须明确提示缺少定位信息，不得伪装成可自动定位的 GeoPDF，也不得凭空指定地图坐标。
- 不承诺 PDF 原始排版中的字体、线型或样式在转换为矢量要素后完全一致；完整页面外观通过栅格加载路径验证。

## 错误处理

对损坏来源、没有可用子图层、缺失驱动、缺少地理参考、连接失败、密码保护和无效图层提供中文反馈及可追溯日志。批量加载允许有效条目成功，对失败条目汇总说明；未注册图层由加载路径负责释放。

## 验收

1. 编译通过；三个入口打开同一原生管理器并定位正确页面。
2. SHP、GeoJSON、含多个矢量图层的 GPKG、GeoTIFF 正常加入图层树并可显示，选择/取消行为正确。
3. 带已知 CRS 和范围的 GeoPDF 可作为栅格按正确位置显示，与参考数据叠加验证定位。
4. 含可读取矢量子图层的 GeoPDF 可选择多个子图层，检查图层名称、几何与属性；多页样例验证页面选择。
5. 普通未定位 PDF、损坏 PDF、取消选择与窗口反复开关均有明确行为且不崩溃。
6. 浏览器及数据库/服务 URI 不被扩展名或本地文件检查拦截；对本机可用类型验证真实添加链路。
7. 用可控样例验证加载及定位；真实用户 GeoPDF 样例尚未提供，最终报告区分可控样例通过与真实文件未验证。
