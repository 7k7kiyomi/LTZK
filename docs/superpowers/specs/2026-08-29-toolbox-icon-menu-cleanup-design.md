# 工具箱菜单清理与圆形图标设计

## 目标

调整地图画布右下角的工具箱入口：仅从工具箱弹出菜单中移除“打开属性表”和“结果面板”两个入口，同时保留它们在其他位置的现有功能；将当前“工具箱”文字按钮替换为圆形 GIS 图标按钮。

## 范围与边界

- 修改 `LTZK.cpp` 中地图画布工具箱菜单的构建逻辑。
- 不删除 `ui.actionOpenAttrTable`，不删除其图层右键菜单入口，也不删除属性表槽函数。
- 不删除结果面板、顶部结果面板按钮或结果面板同步逻辑；只让工具箱菜单不再暴露该入口。
- 新增一个可通过 Qt Resource System 加载的 SVG 图标，并在 `LTZK.qrc` 中登记。
- 不改动其他工具箱菜单项。

## 视觉方案

采用“地图定位针 + 图层网格”的 GIS 语义图标：深蓝色圆形底，青色定位折线/节点，浅色经纬网格，整体保持现有蓝青科技风并在白色、黑色、科幻主题下具有足够对比度。按钮使用图标专用模式，按钮表面透明且无矩形边框，保留“打开平台工具箱”工具提示和鼠标指针反馈。

## 实现方案

1. 新增 `Resources/toolbox_map_pin.svg`，使用 1024×1024 viewBox 和矢量几何，避免不同 DPI 下的位图模糊。
2. 在 `LTZK.qrc` 的 `/LTZK` 资源组登记该 SVG。
3. 在 `createWorkspacePage()` 中将工具箱按钮设为 `ToolButtonIconOnly`，加载 `:/LTZK/Resources/toolbox_map_pin.svg`，按钮使用缩放后的 64×64 方形区域；外层列额外预留 12 个设计像素，并将按钮放在外层左上角，使图标整体向左上方进入画布角框。
4. 对按钮设置 `WA_TranslucentBackground` 和透明内联样式，同时在三套主题 QSS 中增加对象级透明覆盖，避免全局 `QToolButton` 样式绘制矩形背景或悬浮边框。
5. 从 `mapToolboxMenu` 删除 `addAction(ui.actionOpenAttrTable)` 以及“结果面板”菜单动作的添加逻辑；保留结果面板按钮与面板本身的同步代码，避免影响其他界面路径。

## 验证

- 静态回归脚本确认工具箱菜单不再添加这两个动作，同时仍包含打开工程、添加矢量/栅格数据和地图浏览动作。
- 静态回归脚本确认属性表动作连接和图层右键菜单入口仍存在。
- 静态回归脚本确认 SVG 已登记、按钮使用图标专用模式和资源路径。
- 使用现有 Visual Studio 工程执行 Release 编译；若环境不具备完整构建条件，记录实际阻塞原因。
