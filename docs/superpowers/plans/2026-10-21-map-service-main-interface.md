# 地图服务子平台主界面调整

**目标：** 进入地图服务子平台后自动将地图服务管理对话框嵌入内容区，不显示图层管理、地图画布和地图工具栏，保留顶部功能、返回首页和退出账户。

**实现：** 为共用工作台内容区增加地图/服务两页切换容器。继续通过配置的插件动作打开服务管理，在已有插件窗口登记流程中识别 MapServiceDialog，下一轮事件循环将它转为子控件。沿用窗口登记、权限检查、关闭和插件卸载流程。

- [x] 添加真实 Qt 运行测试，验证地图区隐藏、服务对话框嵌入及填充、操作信号、Esc、切换恢复、复用和卸载后重新创建。
- [x] 增加 MapServiceWorkspace，接入模块切换与插件窗口捕获，停用服务模块地图工具栏。
- [x] 运行 Qt 测试、相关现有回归检查及 Release x64 编译；记录验证结果。

**边界：** 仅调整宿主布局，不修改服务单、统计和报表业务。其他地图子平台沿用现有地图及图层状态。服务插件不可用时保留顶部功能按钮以便重试，并显示打开提示。

验证结果：

- `tests/run_map_service_workspace_test.cmd` 编译及运行通过，包含完整容器销毁检查。
- Release x64 最终编译通过，输出为 `map_service_workspace_build/host/LTZK.exe`；编译存在工程原有源文件编码警告及临时输出目录警告。
- 6 项相关检查通过：可伸缩面板、顶部动作共同滚动、编辑工具栏默认布局、质检结果图层模块隔离、插件动作输入约束、全局插件对话框样式。
- 只读代码复核未发现新增实际缺陷。
- 另有现存静态检查未通过：图层树所有权和顶部静态动作脚本依赖已变化的逐字源码格式；结果监测脚本仍要求旧的单参数签名；数据目录脚本解析错误；旧样式事件/文本生命周期脚本禁止当前代码已使用的全局事件过滤及样式刷新。未修改这些无关检查。
- 尚未对登录数据库后的实际服务单、统计和报表操作进行人工验收；这些业务代码及插件 DLL 未改变。
